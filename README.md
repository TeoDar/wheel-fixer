# 🚲 Wheel Fixer

🌐 **Онлайн-версия / Live:** https://teodar.github.io/wheel-fixer/ · [English version](https://teodar.github.io/wheel-fixer/en/)

**RU.** Веб-калькулятор для правки велосипедного колеса («восьмёрка», яйцевидность):
отмечаете на схеме, где обод выпирает, — и получаете список, **какие спицы натянуть,
а какие ослабить** и примерно на сколько.

**EN.** A free bicycle wheel truing calculator: mark the lateral/radial rim runout
(the “8”, a wobble) and get a spoke-by-spoke plan — **which spokes to tighten and
which to loosen**, and by how much.

Чистый HTML/CSS/JS: без сборки, без зависимостей. `index.html` — русская версия,
`en/index.html` — английская; общие `styles.css` и `app.js`. Открывается двойным
кликом по `index.html`.

## Возможности

- Ввод количества спиц (16–48, по умолчанию 32).
- Выбор, на какой фланец идёт спица №1 (L/R) — чтобы схема совпала с вашим колесом.
- Разметка областей **бокового** биения (влево/вправо — «восьмёрка») и
  **радиального** (горб наружу / впадина внутрь).
- Разметка кликом и перетаскиванием, сила отметки 1–3, ластик, отмена (Ctrl+Z).
- Таблица действий по каждой спице: сторона, натянуть `+` / ослабить `−`,
  ориентировочное число оборотов.
- Наглядная подсветка: спицы к подтяжке — зелёные, к ослаблению — оранжевые.
- Пример «восьмёрка» одной кнопкой.
- Адаптивная раскладка: на широком экране — три колонки (колесо / настройки и
  разметка / результаты), на телефоне — компактный режим: колесо сверху,
  панель инструментов прижата к низу, результаты сворачиваются в аккордеон.

## Как пользоваться

1. Закрепите колесо в станке или в перевёрнутой раме.
2. Сторона привода (кассета / трещотка) — это **правая сторона (R)**.
3. Совместите верх схемы со **спицей №1**; нумерация — по часовой стрелке.
4. Мелком/индикатором найдите зоны биения и отметьте их на схеме:
   - красный — выпирает вправо, синий — влево;
   - оранжевый — горб наружу, фиолетовый — впадина.
5. Крутите ниппели по таблице (по 1/4–1/2 оборота), затем проверяйте заново.
   Обычно хватает 2–3 проходов.

**Правило «восьмёрки»:** там, где обод ушёл вправо, натяните левую спицу и
ослабьте правую (и наоборот). Калькулятор сам подбирает нужные спицы.

> Значения оборотов ориентировочные — модель не знает жёсткости конкретного
> обода. Начинайте с меньшего и следите за натяжением («звон» спиц).

## Как это считается

Модель: изменение бокового смещения обода в промежутке `g` от изменения
натяжения спицы `j` равно `s_j · K(d) · t_j`, где `s_j = +1` для спиц на правый
фланец и `−1` для левых, `d` — угловое расстояние между промежутком и спицей
(в шагах), а `K` — гауссово ядро влияния. Радиальное смещение — то же самое без
знака стороны.

Задача «обнулить измеренное биение» решается методом наименьших квадратов с
регуляризацией Тихонова (чтобы правки оставались локальными и практичными):

```
min ‖A·t − b‖² + λ‖t‖²
```

Решение нормальных уравнений — методом Гаусса. Затем натяжения нормируются и
округляются до практичных долей оборота (1/8, 1/4, 3/8, 1/2 …).
